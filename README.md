# 📊 Sample Superstore Power BI Dashboard

## 📌 About This Project

This is my **beginner-level Power BI Data Analytics project** based on the **Sample Superstore dataset**.

I created this dashboard using **Microsoft Power BI Desktop** to understand and analyze sales, profit, quantity, category, segment, region, state, and sub-category data.

The dashboard also contains a **State slicer** that allows users to filter the report interactively.

## 📈 Dashboard Visuals

### 1. KPI Cards

The dashboard shows:

- Quantity
- Profit
- Sales

These values change when the dashboard is filtered.

### 2. Sales by Category

Shows the distribution of sales across different product categories.

### 3. Sales by Segment

Shows sales generated by different customer segments.

### 4. Sales by Region

Shows sales distribution across different regions.

### 5. Profit by State

Shows profit across different states.

### 6. Profit by Sub-Category

Shows which sub-categories generate higher or lower profit.

### 7. State Slicer

The State slicer allows the user to select a state and see the dashboard update accordingly.
